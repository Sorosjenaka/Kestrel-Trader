# Panduan Kestrel Trader (Bahasa Indonesia)

Kestrel Trader adalah sistem trading otomatis untuk Binance USDT-M Futures.
Dokumen ini menjelaskan cara kerja sistem, fitur-fiturnya, dan cara memasangnya —
tanpa detail internal, tanpa parameter risiko, dan tanpa rahasia.
